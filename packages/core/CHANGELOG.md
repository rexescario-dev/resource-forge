# @resource-forge/core

## 0.1.0

### Minor Changes

- Initial public release. Publishes `@resource-forge/core` (resource identity, metadata, registry, Resource model, Operation contracts), `@resource-forge/nest` (Nest discovery/hosting integration), and `@resource-forge/graphql` (GraphQL schema/resolver translation and Operation bindings) to the public npm registry so external consumers can depend on them via normal semver ranges instead of a local checkout.
